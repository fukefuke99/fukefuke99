CAPSTONE · ARDUINO · APP INVENTOR

마찰전기 신호를 교통량 데이터로 바꾸는 시제품

마찰전기 나노발전기의 입력을 계수하고 시간 정보와 함께 저장한 뒤, 스마트폰에서 기간별 교통량을 확인할 수 있도록 센서부터 앱까지 연결했습니다.

역할
팀장, 시스템 통합
제어부
Arduino
저장
RTC, SD 카드
사용자 화면
Bluetooth, App Inventor

센서부터 앱까지

차량이 지나갈 때 발생하는 마찰전기 신호를 Arduino에서 감지해 카운트를 증가시키고, RTC의 시간 정보와 함께 SD 카드에 기록했습니다. 스마트폰이 연결되면 저장된 데이터를 Bluetooth로 전달해 기간별 집계 결과를 확인하도록 구성했습니다.

팀장으로서 센서 입력, 데이터 기록, 통신, 앱 표시가 하나의 흐름으로 이어지도록 통합했습니다. 각 기능을 따로 시연하는 수준을 넘어 실제 사용 순서에 맞춘 시제품으로 완성했습니다.
