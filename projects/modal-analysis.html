MODAL TEST · FRF · MATLAB

시험 데이터에서 모드 형상까지 잇는 분석 환경

상용 분석 소프트웨어의 라이선스 키가 유실된 상황에서 MATLAB 기반 분석 절차를 제안하고, 계측 데이터에서 고유진동수와 감쇠비, 모드 형상을 도출했습니다.

대상
3U 위성 프레임 시험체
계측
가진기, 8채널 가속도계, DAQ
분석
FRF, Peak Picking, LSCE
산출물
3D 모드 형상과 결과보고서

대안 제안

기존 라이선스 키를 찾고 복구 방법을 확인하는 동안 일정이 지체됐습니다. 상용 소프트웨어가 있어야 분석할 수 있다는 전제를 다시 살펴보고, MATLAB과 상용 도구의 성능을 비교한 논문을 근거로 지도교수님과 분석 방식 전환을 협의했습니다.

모달 시험 경험을 보완하기 위해 장비 업체 출장 교육에 참여했습니다. 이후 가진기와 8채널 가속도계로 구조 응답을 계측하고, DAQ에서 취득한 FRF를 MATLAB 분석 단계로 연결했습니다.

분석 결과

채널별 FRF의 크기와 위상을 비교하고, 전체 채널의 응답에서 공통으로 나타나는 모드를 확인했습니다. Peak Picking과 LSCE로 고유진동수와 감쇠비를 구한 뒤 시험점 좌표에 연결해 3차원 모드 형상으로 시각화했습니다.

영상 영역굽힘과 비틀림 모드 애니메이션을 정리한 뒤 배치합니다.
